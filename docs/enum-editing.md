# 枚举字段编辑

错误诊断只改变格子主题，不应禁用枚举字段。已确认的故障包括页面缺少Glide需要的portal、匿名编辑器重挂载/blur重复提交、将数字等原枚举表达式再次JSON字符串化，以及公式enum没有修正入口。结构编辑响应丢effective schema的另一原因由结构响应合同修复处理。

页面补上portal；renderer数组和editor组件保持身份。一次选定即以原始CUE表达式提交一次，blur/escape不会重复提交。显示标签可解码普通JSON字面量，其他合法CUE拼写回退显示原表达式，不凭标签重建源值；nullable enum包含null选项。当前无效值仍可显示并改选。公式单元格保留公式入口，不强制当作普通枚举选择。

真实Chromium回归覆盖有无字段/整行/枚举诊断、manual/auto、数值/布尔/null/转义字符串/引用/无效当前值、语言来回切换、公式bar/inline修正与其他公式不丢；真实Service回归确认原字面量类型、其他非法源输入与公式元数据保持。旧代码portal补齐后的数值探针实际发出两次字符串"2"，新代码只发原始2。

语言切换单独探针未发现读值丢失。用户后续确认的触发是删除行，已用真实Service JSON→浏览器验证结构响应缺失，不将字体或locale变化宣称为根因。浏览器仍不代表所有原生WebKit组合均已验收。
