# Schema import 别名与身份

CUE 源码中的 `shared.#Value` 是词法拼写，应用的规则 ID 仍为实际 package 的 `common.#Value`。读取源时使用 CUE 的词法绑定识别 import；别名不能按字符串直接替换为某个同名 package。索引同时校验本地模块路径、major version 与 package qualifier，另一导入路径的同名规则不能成为错误的引用或删除保护目标。

导入身份保存在 Schema 模型的私有上下文中。源码表达式、打印结果、JSON/Wails DTO 与编辑器显示的 reference 保持原来的别名，未增加数据格式字段；内部校验、循环检查、反向引用和有效类型解析共用这一身份。原无 import 的受限文档继续使用已有 package/本地 ID 规则。

公共定义的本地 package 地址取自最近的 `cue.mod/module.cue`；不会解析或下载远端依赖。模块损坏仍交由编译诊断，不能因这份辅助上下文阻止用户加载和修复受限文档。外部依赖中的规则尚未注册到项目索引时，仍按已有规则报告引用不存在，不虚构本地定义。

回归包括完整编译/CSV 导出、嵌套/数组/nullable 类型、约束、别名循环、错误路径/版本不绑定、局部同名变量不绑定、JSON不泄漏上下文、有效类型与F12导航、保存时保留import别名、被引用规则删除的零写入拒绝。任意CUE表达式、动态包访问不属于此批新增能力。
