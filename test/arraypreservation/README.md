# Array expression preservation regression

`run.cjs WORK APP_BINARY NEW_OUTPUT` uses the actual TypeScript generated App.js bindings, production bridge and session, and AST extracts TableGrid `openInlineAt`, `saveArray`, `finishInlineEdit`, `editCell`, `saveStruct` plus App save/history functions. A synchronous state/ref and timer adapter replaces React scheduling; JSON lines replace Wails IPC. This is neither mounted React nor native GUI testing. List entry mutations represent intended add/delete/reorder states, not executed DOM button clicks.

The binary runs the existing `TestCompactConsistencyPipe` in phase4_bridge_test.go. Every request reaches real Go App/Service, source persistence, diagnostics, Compile and CSV export. The process exits, then a distinct Linux process reopens the same project and exports again. `ARRAY_MODE=after` asserts reference/raw no-op preservation and tests bounded neighboring syntax, exact numbers, literal operations, history, clear/default, explicit empty, quoted struct and FK array fallback. Default mode intentionally runs the old defect and asserts loss; use a frozen phase4 WORK, never the fixed WORK.

`consume.py RUN NEW_RECEIPT` independently reads actual CSV and parses JSON cells with Decimal against literal hardcoded constants. It never imports the JS harness expected values. The only exporter installed in this repository is CSV: array/struct JSON is the actual JSON encoded inside CSV cells, not a claimed standalone JSON exporter.

`go test ./test/arraypreservation -run TestArrayFixturesAreLegalCUE -count=1 -v` loads real CUE files using CUE's own loader and validates concrete rows. `rejected-external.cue` is valid CUE; the application compiles cell expressions in isolated scope and rejects external `_seed` / `list` references. It is excluded from lifecycle project setup. Local let/selector expressions, defaults, conjunction, comprehension, concrete ellipsis conjunction, comments, raw and multiline strings do pass application Compile/Export and arrive in DTOs unchanged.

Nested container checks are pure codec coverage, since product documentation explicitly excludes nested export columns. Numeric parser validation never uses the decoded JSON numeric value, retaining original source slices. Unsupported tokens/grammar return null and use the existing full expression input; bare references are never evaluated and rewritten to values. Missing cell fallback remains existing `[]` behavior; actual empty input calls ClearCell (writes schema default when available), whereas `[]` explicitly clears.

Use datapack5/scripts/control.py for supervision; no installation needed. Dependencies are existing read-only node_modules and Go modules, all writable caches/fixtures/outputs stay in datapack5. Each output directory must be new. Stop at root/local STOP_WORK, quota exhaustion, stale supervisor usage or 22:58 UTC. The run itself also checks those conditions before phases/processes.
